# Weekend Playbook — Fri / Sat / Sun (added 2026-07-29)

Boss has no PC access Fri-Sun but now has a MacBook. Weekends are NOT just
"more weekday." Different channels work.

## The rule: weekends are for DMs, weekdays are for calls

**Why:** barbers, salons and detailers are SLAMMED Saturday. Calling them
mid-cut gets a rushed no and burns the lead. But their customers (and they)
are scrolling social all weekend, so a DM sits there and gets read when they
actually have a second.

| Day | Best move | Avoid |
|-----|-----------|-------|
| Fri | DMs + call the ones who are quiet Fri (detailers, landscapers) | calling salons after 2pm |
| Sat | DM volume day. Send 10-15. | calling barbers/salons at all |
| Sun | DMs + follow-ups. Owners do admin Sunday night. | nothing really |
| Mon-Thu | CALLS. 9:30-11am or 2-4pm. | calling before 9am |

## Weekend routine (~30 min, MacBook)

1. Ask Claude: **"give me today's batch"** -> 10 ready messages in TODAY-SEND.md
2. Send them. One message each. **No double-texting.**
3. Anything that replies -> paste it to Claude immediately, he builds the
   mockup same-day so you answer while they're warm.
4. Report numbers before bed: sent / replies. Claude logs it.

## What Claude does on weekends

- Builds mockups for anyone who replies (same day, every time)
- Sources the next batch of leads so you never open an empty file
- Keeps the ledger + scoreboard current

## Sunday night = the weekly review

- Report every number: sends, replies, mockups sent, money in/out
- Claude self-grades, boss grades Claude
- Set next week's quota based on what the reply rate actually was
